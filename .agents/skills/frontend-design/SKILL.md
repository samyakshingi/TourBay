# Frontend Design Skill

## Design DNA
- **Typography:** Bold headings, high-contrast readability.
- **Hierarchy:** Use purposeful white space to separate "Price" and "Inclusions".
- **Vercel Optimization:** Default to React Server Components. Use "use client" ONLY for interactive filters (price sliders, sort).

## Component Checklist
- [ ] Does it use Tailwind utility classes?
- [ ] Is it responsive for mobile users?
- [ ] Does it handle "Loading" and "Empty" states for the tour list?
